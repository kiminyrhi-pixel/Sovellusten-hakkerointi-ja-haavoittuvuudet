## Make a new version of the passtr.c program where the password doesn't appear directly as-is in the binary. Demonstrate with a test that the password doesn't appear.

Tässä vaiheessa kyselin tekoälyltä mahdollisia tekniikoita salasanan piilottamiseen. Tarjosi useita eri vaihtoehtoja, kuten XOR-hämärtämistä, salasanan pilkkomista ja ASCII-siirtoa. 
Päädyin lopulta ASCII-siirtoon, koska se vaikutti sopivan haastavalta.


<img width="935" height="615" alt="image" src="https://github.com/user-attachments/assets/5a1ef61e-a6dd-475f-8139-0629e746f3e0" />

    'char shifted[] = "tbmb.ibllfsj.432"' 
Alkuperäisen salasanaan jokaisen merkkiin on lisätty 1 kirjain

    char expected[20];
Varataan merkkitaulukko, johon ohjelma purkaa ja kokoaa oikean salasanan RAM muistiin suorituksen aikana.
Silmukka käy sitten shifted taulukkoa läpi merkki kerrallaan, kunnes vastaan tulee nollamerkki, joka päättää funktion.

    expected[i] = shifted[i] - 1; 
Tämä kumoaa aiemman siirron miinustamalla jokaisen merkin arvosta yhden taaksepäin

    expected[i] = '\0';
 Lisää purettuun tekstiin perään merkkijonon lopetusmerkin. 

    if (0 == strcmp(password, expected))   
Tällä vertailu toimii täysin normaalisti, mutta strings ei näe salasanaa.
